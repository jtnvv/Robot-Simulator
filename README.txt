Robotic Factory simulator (Java).
Compile the sources in src/ with the jars in libs/ on the classpath.
Start fr.tp.inf112.projects.robotsim.app.FactoryPersistenceServer, then fr.tp.inf112.projects.robotsim.app.SimulatorApplication.
For workshops 3 and 4, also start the Spring Boot service in fr.tp.slr201.projects.robotsim.service.simulation and a Kafka broker.
